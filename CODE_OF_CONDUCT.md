# Code of Conduct

## Our pledge

This project is committed to providing a welcoming, friendly, and
harassment-free experience for everyone who participates — contributors,
maintainers, and users alike — regardless of background or identity.

## Our standard

This project adopts the **Contributor Covenant, version 2.1** as its code
of conduct. The full, canonical text of the standards we hold ourselves to
— expected behaviour, unacceptable behaviour, scope, and enforcement
guidelines — is published here:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain-text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.md>

By participating in this project — opening issues or pull requests,
commenting, or otherwise contributing — you agree to uphold that standard
in all project spaces and in public spaces when representing the project.

## Reporting

If you experience or witness unacceptable behaviour, please report it to the
maintainer, [@yannickgranger](https://github.com/yannickgranger), by opening
a private GitHub security advisory on the repository or by direct message.
All reports will be reviewed and investigated promptly and fairly, and the
reporter's privacy and safety will be respected.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code of
conduct and will take appropriate, fair corrective action in response to any
behaviour they deem inappropriate, following the **Enforcement Guidelines**
in the Contributor Covenant 2.1 linked above (Correction → Warning →
Temporary Ban → Permanent Ban).
